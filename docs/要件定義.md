# 2Dワイヤーアクションゲーム要件定義

## プロジェクト概要

**ジャンル**: 2D縦型強制スクロール・ワイヤーアクション・エンドレス型ゲーム  
**プラットフォーム**: PC  
**開発環境**: Unity 6.2  
**画面比率**: 16:9

## ゲームコンセプト

プレイヤーはワイヤーを駆使して上昇し続ける2Dアクションゲーム。下から迫るマグマから逃れながら、可能な限り高い高度を目指す。

## コア仕様

### 基本システム
- **ゲームタイプ**: エンドレス型（死ぬまで続く）
- **視点**: 2Dサイドビュー
- **カメラ**: プレイヤー追従
- **強制スクロール**: 下からマグマが時間経過で加速しながら上昇
- **死亡条件**: マグマ接触 または 棘接触

### プレイヤーキャラクター
- **形状**: 円形
- **当たり判定**: 円に沿った判定
- **基本アクション**: 地上移動、ジャンプ、ワイヤーアクション

## 操作仕様

### 入力方法
| 入力 | 動作 |
|------|------|
| マウスカーソル | ワイヤー照準 |
| マウスクリック | ワイヤー射出 |
| A/D | 地上での左右移動 |
| W/A/S/D | 壁張り付き時の移動 |
| Space | ジャンプ |
| Z | 張り付き解除 |

### ワイヤーシステム詳細

#### 射出・巻取り
- **射程**: 画面内まで
- **予測線描写**: 予測線は点線で表現され、長さは射程分まで。デフォルトが白でワイヤー射出条件を満たすと緑色の点線になる。
- **ワイヤー描写**:白の実線。予測線と同時に描写される。。



- **射出条件**: オブジェクトをクリックした時のみ（Player自身以外）。また、判定にTagは用いない
- **巻取り**: 射出後、自動で巻取り開始（速度：速め）

- **同時使用**: 1本のみ

#### 張り付きシステム
- **張り付き条件**: 巻取り中に壁または天井にぶつかる
- **張り付き状態**: 重力無視、W/A/S/Dで移動可能、ジャンプ不可、ワイヤーを新たに射出可能。
- **移動速度**: 通常移動と同速度
- **解除方法**: Zキー 

#### 物理挙動
- **慣性継承**: ジャンプでワイヤー巻取りキャンセル時、ワイヤー巻取り移動の慣性を約半分継承
- **表示**: ワイヤー軌道を直線で表示

## ステージ仕様

### 画面構成
- **幅**: 固定
- **境界**: 左右は壁扱い
- **スクロール**: 縦方向上向き強制スクロール

### 地形要素
- **基本地形**: 壁、天井、平地
- **障害物**: 棘（接触即死）
- **特殊地形**: なし（初期版）

### ステージ生成
- **方式**: 予め作成したパターンの組み合わせ
- **密度**: ワイヤー移動を前提とした間隔設定

## UI・スコアシステム

### スコア
- **基準**: 到達高度
- **表示**: リアルタイム表示
- **記録**: 保存機能なし

### UI要素
- **リアルタイムスコア表示**
- **ワイヤー軌道表示**
- **ゲームオーバー時の最終スコア表示**

## 技術仕様

### 開発環境
- **Unity**: 6.2
- **プラットフォーム**: PC
- **画面解像度**: 16:9比率対応

### 物理設定
- **重力**: あり（張り付き時は無効）
- **当たり判定**: 2D物理演算使用
- **慣性**: リアルとアーケード的操作感のバランス
